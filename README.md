# Prácticas de wxMaxima · Matemáticas 2

Cuaderno para el Grado en Fundamentos de Arquitectura de la Universidad Politécnica de Cartagena, curso 2026/27. Adaptación del cuaderno de prácticas del profesor Guillermo Salinas Martínez.

Descarga [el cuaderno en formato .wxmx](Cuaderno_Practicas_Matematicas_2.wxmx) y ábrelo con wxMaxima. Incluye las prácticas de cálculo diferencial e integral, con 12 ejercicios resueltos, comprobaciones y gráficas. Para ejecutar una celda, pulsa **Mayús + Intro**.

## Práctica de cálculo diferencial para el alumnado

Descarga la [práctica sin soluciones](Practica_Calculo_Diferencial_Alumnado.wxmx). Contiene ocho ejercicios nuevos y celdas para escribir y ejecutar la resolución. Añade tu nombre, apellidos y grupo. Guarda el archivo como `Apellidos_Nombre_Diferencial.wxmx` con los resultados visibles y entrégalo en la tarea del Aula Virtual.
